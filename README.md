# AIRNOTE

AIRNOTE is a Solana Mobile experiment for hardware-backed, USDC-funded offline payments using single-use payment credentials on Seeker.

The project is being built in gated milestones. **Gate 00** validates the foundational assumption: whether the physical Seeker can enforce a hardware-backed P-256 signing key that can be used exactly once.

> Status: repository initialized. Gate 00 implementation is under active development.
